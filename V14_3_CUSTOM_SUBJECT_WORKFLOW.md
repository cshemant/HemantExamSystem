# V14.3 Custom Subject Question Workflow

This update removes the ambiguity between the Subject Catalog and the preloaded Question Bank library.

When faculty select a custom subject such as **Indian Knowledge System**, the page now opens a dedicated subject workspace showing:
- catalog/category status
- total, approved and draft question counts
- **Add Question** shortcut
- **Upload CSV / Excel** shortcut
- subject-specific CSV and Excel templates
- direct link to the subject's existing bank questions

Custom subjects are already active in the Subject Catalog when created. The preloaded **Activate Bank** action applies only to ready-made starter banks. For custom subjects, faculty add/import questions and approve them before using them in exams.

Bulk upload from a selected subject workspace automatically assigns all imported rows to that selected subject/category, preventing accidental import into another subject.
