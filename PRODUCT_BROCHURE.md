# Hybrid Examination Management System

**Offline on campus. Online when required.**

A configurable examination platform for colleges and universities that can conduct assessments on a local LAN without Internet dependency and can also run online with PostgreSQL.

## Institution-ready capabilities
- White-label institution name, logo, department and academic year
- Super Admin, Exam Controller, HOD, Faculty and Student workflow
- Batch / semester / section management
- Bulk student import with automatic batch assignment
- Reusable Question Bank with Unit, Difficulty, Bloom and CO mapping
- Exam blueprint and randomized paper generation
- Approval workflow before exam activation
- Batch-wise scheduling and venue assignment
- Offline LAN Exam Centre screen with student URL + QR code
- Autosave, resume, automatic scoring and browser-level activity monitoring
- Results export, class statistics, pass percentage, CO/unit attainment and item analysis
- Audit trail, question versioning, inactivity timeout and encrypted offline backups

## Recommended pilot
Conduct one departmental exam for 50–100 students using the institution's existing LAN. No Internet connection is required during the offline exam.
